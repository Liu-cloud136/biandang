## 三、自动闭环（本次最大成果）

矛盾从发现到修复的全自动管道打通，人工介入点只剩「救援 3 次都失败的极端顽固户」（当前 0 道）：

```
六维扫描发现矛盾（自动补扫，新增即检）
  → 自动入返工（createReworkTask force+auto，dims=四文本维 → repair=consistency）
  → runReworkTask：env1 直修优先（≤2 次/任务，ENV1_FIX_TASK_MAX）
      ✓ 通过 → archiveReworkTaskDone 关单（不动 env2）+ 清复扫计数
      ✗ 未过 → syncBaseToMirror → env2 自洽修复 → 逐维写回 env1
  → AI 复核（pumpReworkAi）→ autofix：通过自动 approve / 未过自动重试
  → 3 轮上限留人工 → 零延迟自动救援（见下）×3 → 仍不过才等人工
```

关键改动：
- **矛盾自动入队**：dimScan 发现 `pass:false` 即 `createReworkTask`（含矛盾明细作修正要求）；每次启动扫描先 `backfillDimRework` 补入历史矛盾，并把早期 `'all'` 维存量任务规范化为四文本维 consistency。
- **env1 先消化**：`runReworkTask` 对 auto consistency 任务先试 `env1DishFix` 点状直修，通过直接关单（专门加了 `archiveReworkTaskDone`，绕开 approveReworkTask 防旧 mirror 反覆盖）。实测约七成矛盾由 env1 直修一次过。
- **留人工零延迟救援**：`MANUAL_RESCUE_DELAY` 90s → **0**（用户拍板「直接走动作」），留人工立即触发：env1 点状直修 ≤3 次 → 一致性修复，每道最多救援 3 次。
- **关单清复扫计数**：`clearRescanFor` 在 env1 直修关单和 approve 关单两处调用，修好的菜不再顶着「稳定问题」显示残留。
- **env1DishFix 增强**（BUILD_TAG=2026-09-13.env1-dishfix-profile-main）：新增**确定性主料修正**——问题涉画像/主料时，主料直接取食材清单前 1~2 个非调料条目名（不走 AI，规则推导），解决「画像主料 vs 食材清单」类病灶 AI 补丁修不到根的问题（酱爆螺蛳案例：画像「螺蛳肉」vs 实际「带壳螺蛳」）。
- **配额错误不再计永久 skip**：时令打标写入撞 `LimitExceeded/OutOfWrite` 计 fail（可重试）而非永久 skip。

## 九、事故与教训（重要）

1. **写配额爆**：返工波次 5 万+写/日 → `OutOfWriteRequestQuota` 2025 次。管线重试自愈绝大部分，终态仅 2 道残缺（均已修）。→ writeGate 节流器根治。
2. **游标分页漏行**：TCB get 不带 `orderBy('_id','asc')` 不保证 _id 序，分页会漏 → 审计假阴性（曾误判 4913 道缺表）。所有分页必须显式排序。
3. **改状态文件被缓存复活**：直接改 `data/*.json`（清复扫计数/清 skipList）被 server 内存缓存回写覆盖——**必须配合重启**或走 API。
4. **python 多段补丁部分写入**：一次断言中止导致 `clearRescanFor` 定义丢失（调用在、定义不在 = approve 路径运行时 ReferenceError）。→ 多段补丁必须逐段 grep 验证落盘。
5. **思考型模型 content 为空**：step 系思考文本在 `message.reasoning`，max_tokens 不足时 content 空；低推理开关=`reasoning:{effort:'low'}`，抽取逻辑须带 reasoning 尾部 JSON 兜底。
6. **额度≠限速**：429 是 RPM/并发上限、503 是服务端抖动，看 token 额度仪表盘没用。
7. **Git Bash curl 发中文会 GBK 乱码**：用 python urllib 或文件体。
8. **Bash 后台任务 cwd 漂移 / kill %1 跨调用无效**：一律绝对路径 + 按端口 netstat 找 PID 杀。
9. **bypass* 函数并未部署为云函数**：review-web 的逐维重生成全靠服务端本地补写模拟（FUNCTION_NOT_FOUND 实锤）。
10. **wx-server-sdk doc.set**：data 禁带 _id；node-sdk 收裸对象；直连 node-sdk 对不存在集合 set 不自动建（先 createCollection）。
